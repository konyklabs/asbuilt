# Refund policy

The formal policy behind refunds, written so support has an authoritative page to point to instead of relying on tribal knowledge about what's allowed. Pairs with the wiki's refunds process page, which covers the same ground in a more conversational tone.

## Purpose

Riders deserve a predictable answer when they ask for money back, and fares needs a consistent standard to apply so two riders with the same situation don't get two different outcomes depending on who reviews the request.

## Window

A refund has to be requested within 14 days of the ride's end. Requests that come in after that window closes are rejected outright, with no discretionary exception available to whoever's reviewing it — the window is firm by design, not a soft guideline.

## Limits

A refund can never exceed what the ride actually cost. If a rider is asking for compensation beyond that — for lost time, for inconvenience, anything beyond the charge itself — that's a goodwill gesture handled outside this policy, not a refund in the sense this document covers.

## Auto Approval

When the refund_auto_approve flag is on, a request under $5.00 gets approved automatically, without a fares agent looking at it first. Everything at or above that amount still goes through manual review exactly as it always has; this only removes the wait for the smallest requests.

## Fraud and abuse

A pattern of frequent small refund requests from the same account should be flagged to fares even if each individual request is small enough to auto-approve — the auto-approval path is meant to speed up legitimate requests, not to create a blind spot for abuse.

## Escalation

If a request doesn't cleanly fit any of the categories above — a partial refund, a request tied to a disputed lost-bike fee, anything unusual — don't try to force it into the closest matching rule. Escalate to fares directly and let a human make the call rather than approving or rejecting based on a guess.

## Ownership

Fares owns this policy and any change to it. Support and other teams are welcome to flag a case that seems to fall through the cracks, but the actual wording here only changes with fares sign-off.
