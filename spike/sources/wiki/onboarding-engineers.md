# Engineer onboarding

Checklist and orientation notes for a new engineer joining fleet, fares, or ops. Read this before your first day, not during your first standup.

## Repository

All three services — dockyard, farebox, dispatch — have lived together in a single repository since 2026-01-12. If someone points you at an old link for a separate dockyard or farebox repo, it's stale; everything you need is in the one place now, organized by service directory rather than by repo.

## First week

Get local checkouts of all three services running before you touch anything, even if you're only going to be working in one of them — a lot of local testing depends on being able to spin up the others too. Ask in the team channel if the setup docs are out of date; they usually are, a little.

## Who to ask what

Fleet questions go to Priya or Sami, fares questions go to Mara or Kasia, ops questions go to Ren or Tobin. If you're not sure which team owns something, Gearwell platform overview has the service-to-team mapping.

## Related pages

Gearwell platform overview is the map of the whole platform. Data model has the schema details you'll need once you start writing queries against anything shared.
